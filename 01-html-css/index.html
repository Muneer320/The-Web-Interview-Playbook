HTML & CSS Interview Preparation

HTML and CSS interviews test whether you can build real, accessible, responsive UIs — not whether you’ve memorized every CSS property.

What Interviewers Look For

  • Semantic HTML (not div soup)
  • Layout skills (Flexbox, Grid — not just Bootstrap classes)
  • Responsive design thinking
  • Basic accessibility awareness
  • CSS specificity and cascade understanding

CSS Specificity Calculator

Type two competing selectors and see the (IDs, classes, elements) scores battle — and why source order breaks ties.

Left wins. Compare left-to-right: one ID beats any number of classes; one class beats any number of elements.

Scores are (IDs, classes+attributes+pseudo-classes, elements+pseudo-elements). Simplified: :not()/:is()/:has() wrappers count zero but their arguments count; :where() counts zero entirely; comma lists score as their highest selector; inline styles and !important sit outside this comparison.
