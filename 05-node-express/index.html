Node.js & Express Interview Preparation

Backend interviews test whether you can build APIs, handle auth, and reason about server-side concerns — not just copy Express boilerplate.

What Interviewers Look For

  • REST API design
  • Middleware understanding
  • Authentication & security basics
  • Error handling and validation
  • Database integration patterns
  • How your project backend is structured

Express Middleware Pipeline

Follow a request through logger → auth → validate → handler, short-circuit a 401, and crash into the error middleware.

app.use(logger);app.use(auth);app.post('/orders', validate, handler);app.use(errorHandler);
request→logger→auth→validate→handler→error mw→response
  • 📝 logged: POST /orders

POST /orders arrives. Middleware run IN REGISTRATION ORDER; each calls next() to pass the request on.

JWT: Sign, Verify, Tamper

Edit a real token signed live in your browser, then tamper the payload and watch the signature scream — the whole JWT security model in one box.

header (fixed)
{"alg":"HS256","typ":"JWT"}
payload — edit me
secret — the server's, never the client's
..
… verifying

The signature covers exactly the bytes of header.payload. Change one character — by hand or with Tamper — and verification fails. Fix it by editing the payload pane instead: that re-signs with the secret, which an attacker doesn't have.

POST /login { user, pass }← 200 { token }GET /ordersAuthorization: Bearer <token>← 200 [ ...orders ]
clientcredentials →server

The client proves identity ONCE, with credentials.
